# Security notes

This repository is a portfolio project using fictional test data.

Do not commit:

- Microsoft 365 passwords or MFA recovery data
- OAuth tokens, cookies, client secrets, or access tokens
- Power Automate connection references containing sensitive values
- tenant secrets or private environment identifiers
- real customer, employee, order, or operational data
- production workbook paths containing confidential information
- screenshots containing private email addresses or credentials

The public repository includes source code, documentation, sample data, and sanitized screenshots rather than production connection exports.
