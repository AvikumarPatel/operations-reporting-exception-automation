## Short GitHub / LinkedIn description

Built a Microsoft 365 operations automation that processes warehouse-style operational data with VBA, orchestrates Excel through Power Automate Desktop, reviews KPI outputs with Office Scripts, and routes exceptions through Power Automate Cloud using Outlook and Teams.

## Interview explanation

I built the project to get hands-on experience with both desktop and cloud automation in the Microsoft ecosystem. Excel VBA handles the data-processing layer: it validates records, calculates error, late-order, return, and productivity KPIs, and creates an Exceptions worksheet. Power Automate Desktop opens the workbook, runs the VBA, reads the KPI outputs, evaluates whether exceptions exist, and saves/closes Excel automatically. I then created a macro-free cloud copy in OneDrive for Business. An Office Script reads the KPI summary and returns a structured object to Power Automate Cloud. The cloud flow uses the exception count for True/False routing, sends review-required or no-exception emails through Outlook, includes a Teams notification action for exception cases, and has both manual-test and recurrence-based versions.
